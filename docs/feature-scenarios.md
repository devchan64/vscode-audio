# Audio Wave Editor 기능 시나리오

## 시나리오 관리 규칙

기능 ID는 `FS-xxx` 형식으로 관리한다. 구현 상태는 `지원`, `부분 지원`, `후속 구현` 중 하나로 표시한다.

## 파일 열기와 파형

### FS-001 디코드 가능한 오디오 파일 열기 — 지원

사용자가 Command Palette의 `Audio Wave Editor: Open` 또는 VS Code의 `Open With... → Audio Wave Editor`로 파일을 연다. Webview는 `decodeAudioData`를 호출하고 성공한 경우에만 duration, sample rate, channel 수를 표시한다. 확장자와 MIME은 파일 선택 보조 정보일 뿐 지원 판정이 아니다.

### FS-003 드래그 앤 드롭 — 지원

디코드 가능한 오디오 파일을 Webview에 드롭하면 기존 버퍼를 교체하기 전에 새 파일을 로드한다. 로드 실패 시 기존 버퍼와 재생 상태는 유지한다.

### FS-004 파형 표시 — 지원

첫 번째 채널의 peak envelope를 캔버스에 표시한다. 파일이 없을 때는 빈 상태 안내를 표시하고, 긴 파일에서도 UI가 멈추지 않도록 화면 폭 기준으로 downsample한다.

### FS-005 채널별 타임라인 — 지원

각 채널을 같은 시간축의 lane으로 표시하고 선택 영역과 playhead를 모든 lane에 정렬한다.

### FS-006 타임라인 선택 — 지원

드래그·핸들·키보드로 sample frame 범위를 선택하고, 대상 채널 또는 전체 채널을 명시한다.

### FS-007 아날로그 타임라인 차트 — 부분 지원

시간 눈금, dB 기준선, 채널별 lane, 선택 영역, 재생 헤드를 하나의 시간 좌표계로 표시한다. 줌과 가로 스크롤 중에도 눈금·파형·선택 경계가 같은 시간 위치를 가리켜야 한다.

## 재생과 선택

### FS-010 구간 선택 — 지원

시작·끝 슬라이더로 재생 구간을 지정한다. 시작은 끝보다 클 수 없으며, 시간과 파일 전체 대비 위치를 함께 표시한다.

### FS-011 선택 구간 재생 — 지원

Play는 선택 시작점에서 처리된 버퍼를 재생한다. Stop은 현재 소스를 중지하고 다음 Play를 위해 새 소스를 생성한다.

### FS-012 편집 재생 미리 듣기 — 부분 지원

채널 게인과 EQ 값을 적용한 결과를 미리 듣는다. 현재는 trim/fade/undo 없이 현재 설정을 버퍼 전체에 적용한다.

## 오디오 처리

### FS-015 Cut/Copy/Paste/Delete — 지원

선택 frame을 기준으로 편집하고, 채널 간 시간축을 유지한다. Paste는 mono/stereo 변환 정책을 적용한다.

### FS-016 선택 영역 이펙트 — 지원

선택 영역 또는 전체 영역에 Normalize, Gain, EQ를 적용하고 Apply 후 Undo를 제공한다.

### FS-020 채널별 게인 — 지원

각 채널을 0–200% 선형 배율로 조절한다. 모든 샘플은 [-1, 1]로 clamp하여 clipping을 방지한다.

### FS-021 3-band EQ — 지원

Low/Mid/High 보정값을 -12–12 dB로 조절한다. MVP는 기본적인 주파수 구간 보정이며 정밀한 parametric EQ가 아니다.

### FS-022 Normalize — 지원

선택한 트랙 또는 전체 채널에서 Selection/Entire document 범위의 peak를 찾아 -1 dBFS가 되도록 스케일링한다. 무음 파일은 변경하지 않고 상태를 표시한다.

### FS-023 믹싱 — 지원

스테레오를 두 채널 평균의 mono 버퍼로 합친다. 원본 채널 수가 1이면 동작하지 않고 안내한다.

## 내보내기와 오류

### FS-030 WAV 내보내기 — 지원

현재 게인·EQ가 반영된 PCM16 WAV를 저장 대화상자에 지정한 경로로 쓴다. 출력 형식은 WAV이며 MP3 인코딩은 제공하지 않는다.

### FS-031 저장 실패 — 지원

경로 접근 거부, 취소, 인코딩 실패를 성공으로 표시하지 않는다. 사용자가 다시 저장하거나 다른 경로를 선택하도록 안내한다.

### FS-032 대용량 파일 — 후속 구현

현재는 Webview 메모리에 전체 AudioBuffer를 보관한다. 스트리밍 디코드, 작업 취소, 진행률은 후속 범위다.
