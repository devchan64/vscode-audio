# Audio Wave Editor 기능 시나리오

## 시나리오 관리 규칙

기능 ID는 `FS-xxx` 형식으로 관리한다. 구현 상태는 `지원`, `부분 지원`, `후속 구현` 중 하나로 표시한다.

## 파일 열기와 파형

### FS-001 디코드 가능한 오디오 파일 열기 — 지원

사용자가 Command Palette의 `Audio Wave Editor: Open` 또는 VS Code의 `Open With... → Audio Wave Editor`로 파일을 연다. Webview는 `decodeAudioData`를 호출하고 성공한 경우에만 duration, sample rate, channel 수를 표시한다. 확장자와 MIME은 파일 선택 보조 정보일 뿐 지원 판정이 아니다.

### FS-003 드래그 앤 드롭 — 부분 지원

독립 Webview에 디코드 가능한 오디오 파일을 드롭하면 기존 버퍼를 교체하기 전에 새 파일을 로드한다. 디코드 실패 시 기존 버퍼와 재생 상태는 유지한다. 커스텀 에디터는 드롭 대신 VS Code에서 파일을 열도록 안내한다.

### FS-004 파형 표시 — 지원

각 채널의 peak envelope를 캔버스에 표시한다. 파일이 없을 때는 빈 상태 안내를 표시하고 화면 폭 기준으로 downsample한다. 실제 긴 파일의 처리 지연은 추가 측정이 필요하다.

### FS-005 채널별 타임라인 — 지원

각 채널을 같은 시간축의 lane으로 표시하고 선택 영역과 playhead를 모든 lane에 정렬한다.

### FS-006 타임라인 선택 — 지원

드래그·핸들·키보드로 sample frame 범위를 선택하고, 대상 채널 또는 전체 채널을 명시한다.

### FS-007 아날로그 타임라인 차트 — 부분 지원

시간 눈금, dB 기준선, 채널별 lane, 선택 영역, 재생 헤드를 하나의 시간 좌표계로 표시한다. 줌과 가로 스크롤 중에도 눈금·파형·선택 경계가 같은 시간 위치를 가리켜야 한다.

## 재생과 선택

### FS-010 구간 선택 — 지원

시작·끝 슬라이더나 타임라인 드래그로 재생 구간을 지정한다. 타임라인을 클릭하면 선택 없는 재생 커서가 이동하며, Play는 그 위치부터 파일 끝까지 재생한다. 시작은 끝보다 클 수 없으며, 시간과 파일 전체 대비 위치를 함께 표시한다.

### FS-011 선택 구간 재생 — 지원

Play는 선택 시작점에서 재생한다. Pause는 현재 위치를 보존하고 다시 Play하면 이어 재생한다. 선택 끝에 이미 도달한 시점의 Pause는 재생 완료로 처리하므로 다음 Play는 선택 시작점에서 다시 재생한다. Stop은 소스를 중지하고 선택 시작점으로 돌아간다.

### FS-012 편집 재생 미리 듣기 — 부분 지원

채널 게인과 EQ 값을 실시간 오디오 그래프에서 미리 듣고 재생 중 조절할 수 있다. Fade와 Undo는 편집 명령으로 지원하고 trim은 후속 기능이다.

## 오디오 처리

### FS-015 Cut/Copy/Paste/Delete — 지원

선택 frame을 기준으로 편집하고, 채널 간 시간축을 유지한다. Paste는 mono/stereo 변환 정책을 적용한다. 클립보드는 현재 Webview에 한정되며 새 파일을 성공적으로 열면 초기화된다.

### FS-016 선택 영역 이펙트 — 지원

선택 영역 또는 전체 영역과 대상 채널에 Normalize, Gain, EQ를 적용하고 Undo/Redo를 제공한다. Fade는 선택 구간에 적용한다. EQ 적용 후 미리 듣기 EQ는 초기화된다.

Fade는 두 프레임 이상의 선택에서 사용할 수 있다. 대상 채널의 선택 영역이 무음이면 샘플과 편집 이력을 변경하지 않는다.

### FS-020 채널별 게인 — 지원

각 채널을 0–200% 선형 배율로 조절한다. 적용 또는 출력 결과는 [-1, 1]로 제한한다.

Gain 적용 시 대상 게인이 모두 100%이고 샘플이 허용 범위 안에 있으면 오디오와 편집 이력을 변경하지 않는다. 범위를 넘는 샘플은 100% 게인에서도 클리핑한다.

### FS-021 3-band EQ — 지원

Low/Mid/High를 -12–12 dB로 조절한다. 250 Hz lowshelf, 1 kHz peaking, 4 kHz highshelf를 사용하며 정밀한 parametric EQ는 아니다.

### FS-022 Normalize — 지원

선택한 트랙 또는 전체 채널에서 Selection/Entire document 범위의 peak를 찾아 -1 dBFS가 되도록 스케일링한다. 대상이 무음이면 변경과 편집 이력 없이 상태를 표시한다.

### FS-023 믹싱 — 지원

스테레오를 두 채널 평균의 mono 버퍼로 합친다. 원본 채널 수가 1이면 오디오를 변경하지 않는다.

## 내보내기와 오류

### FS-030 WAV 내보내기 — 지원

현재 게인·EQ가 반영된 PCM16 WAV 또는 mono/stereo MP3를 저장 대화상자에 지정한 경로로 쓴다. 선택한 형식과 확장자가 일치하지 않으면 쓰지 않는다. 버전 내보내기는 원본 옆에 형식별 최대 번호의 다음 번호를 사용하며 기존 파일을 덮어쓰지 않는다. 원본 URI를 알 수 없으면 저장 대화상자를 사용한다.

### FS-031 저장 실패 — 지원

WAV 내보내기 대화상자의 취소, 파일 쓰기 실패와 성공을 각각 상태에 표시한다. 쓰기 실패 시 다른 경로를 선택해 다시 시도하도록 안내하며 성공 알림은 실제 쓰기 완료 후에만 표시한다.

### FS-032 대용량 파일 — 후속 구현

현재는 Webview 메모리에 전체 AudioBuffer를 보관한다. WAV의 RIFF 크기 제한을 넘는 내보내기는 오프라인 렌더링과 출력 버퍼 할당 전에 중단하고 상태를 표시한다. 스트리밍 디코드, 작업 취소, 진행률은 후속 범위다.
